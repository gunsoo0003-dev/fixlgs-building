FIX BUILDING — ANALYSIS V020 PRICE ENGINE 1:1 CROSSWALK

목적
- PRICE 콘텐츠를 별도 일반론으로 채우지 않는다.
- 기존 FIX PRICE 엔진의 실제 분석로직을 일반 사용자가 빠르게 이해하도록 풀어쓴다.
- 엔진 노드가 가진 판단요소가 화면에서 사라지지 않는지 1:1 대조한다.

PRICE 01 — 호가는 출발점일 뿐
엔진: 호가를 시장기준으로 쓰지 않음 / 판단보류 / 외부 비교기준 생성 / 앵커링 주의
화면: “왜 호가를 바로 시장가격으로 보면 안 될까?”
PASS: 호가의 의미 + 판단보류 이유 + 다음 비교거래 필요성까지 설명

PRICE 02 — 비교거래 선택
엔진: 규모·연식·공실·입지·상태 비교 / 차이 기록 / 임의 선택 금지
화면: “왜 비교거래는 가까운 건물이 아니라 비슷한 건물이어야 할까?”
PASS: 비교가능성의 이유와 조건차이 기록 목적까지 설명

PRICE 03 — 단위가격 비교
엔진: 총액에서 규모효과 분리 / 평당가·㎡당가 보조 / 적정가 자동판정 금지
화면: “왜 총가격을 본 뒤 평당가를 한 번 더 볼까?”
PASS: 단위가격의 필요성과 한계를 동시에 설명

PRICE 04 — 조건차이 조정
엔진: 연식·공실·입지·상태가 가격차이를 설명 / 임의 점수화 금지
화면: “왜 가격 차이를 바로 비싸다·싸다로 해석하지 않을까?”
PASS: 가격차이 → 조건차이 → 해석변화의 이유를 설명

PRICE 05 — 프리미엄 근거
엔진: 비교범위 상단이면 더 높은 가격을 설명할 실제 장점 확인
화면: “왜 비교범위의 높은 쪽이면 프리미엄 근거를 찾을까?”
PASS: 높은 가격 자체가 문제가 아니라 근거 유무가 핵심임을 설명

PRICE 06 — 수익구조 교차검증
엔진: 높은 가격이 INCOME으로 설명되는지 확인 / 6.4% vs 약4.7% 기준차이
화면: “왜 가격 분석의 마지막에 수익을 다시 연결할까?”
PASS: 가격↔수익 연결 이유와 이번 엔진 수치까지 설명

PRICE 07 — 가격축 판정
엔진: 비교범위 상단 + 추가장점 미확인 → 가격 다소 불리 / 전체 매수결론 아님
화면: “왜 가격축 판정을 건물 전체 결론으로 확대하지 않을까?”
PASS: 축판정 범위와 전체결론 구분 설명

용어 통제
- 사전식 한 줄 정의를 제거.
- 각 용어를 가격 분석에서 어떻게 구분하고 왜 조심해야 하는지로 설명.
- 매매가 / 시세 / 실거래가 / 평당가 / 공시지가 / 공시가격 / 감정가 유지.

실전 통제
- V019의 별도 16억 예시 대신 기존 PRICE 엔진 15억 CASE를 재사용.
- 대상 15억 / 비교 14.2·15.1·13.8억 / 만실 6.4% → 공실·운영비 반영 약4.7%.
- 사용자 시험형 선택을 PRICE에서는 제거하고 엔진 결과와 이유를 바로 보여줌.

완료판정
- PRICE 01~07 = 7/7 화면 설명 존재
- 엔진의 이유·주의·판정범위 누락 0
- 새 일반론으로 밀도 채우기 0
- 엔진 CASE와 다른 임의 가격예시 제거
